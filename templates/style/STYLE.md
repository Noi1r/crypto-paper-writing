# Writing style

Optional project profile, created only when the author asks for one. The default
new-paper workflow records paper-specific writing references and a plan in
`STATE.md`. Fill this separate profile from the author's explicit preferences or
selected samples using `.paper-writing/skills/polish-writing/references/author-style.md`.
An empty table does not impose a style. Inferred observations remain candidates
until the author adopts them; current instructions and technical meaning govern
their use.
