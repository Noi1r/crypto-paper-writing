# Appendix

Use the appendix for detailed supporting material when the target venue permits
it. Check how appendices are submitted, counted and reviewed before deciding
where essential material belongs.

The main text should make the problem, main statements, assumptions and central
ideas understandable. Complete proofs, additional analyses, specification detail
or extended experimental results may appear in the appendix with precise
references from the body. Proof placement is a presentation decision; it does
not change the obligation to support the stated result.

Give each appendix section a clear purpose and identify the body statement it
supports. Keep notation and theorem references consistent. Generate expanded
tables from the same data as the main tables.

If different submission, proceedings and full versions share source files,
check the dependencies in each intended build. Readers need access to the
supporting material referenced by that version under the venue's rules.
