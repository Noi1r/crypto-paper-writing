# Conclusion

A conclusion is optional when venue requirements permit its omission and the
paper already communicates its results clearly.

Include one when it provides a useful closing synthesis: what the established
results mean, the main tradeoff or limitation, or a concrete question that remains.
Use the level of detail needed for that purpose. Avoid merely repeating the
abstract or listing what each section contained.

Check that the conclusion introduces no unsupported result. Any repeated values
or technical statements must have the same scope as the body. An open question
should be identifiable as future work rather than an implicit claim already met.
