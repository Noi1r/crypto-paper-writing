# Prepare literature and references

Read `STATE.md` and the paper's current question. Search IACR ePrint, DBLP,
Crossref, and relevant venues; use `.paper-writing/skills/eprint-search`, `.paper-writing/skills/lit-matrix`,
`.paper-writing/skills/reading-notes`, and `.paper-writing/skills/bib-verify`. Read the papers that bear on
novelty or comparison rather than relying on metadata or abstracts.

Write `LITERATURE.md` as a matrix with setting, method, exact comparable claim,
source location, and the paper's delta. Put reading notes under `notes/papers/`.
Add only verified entries to `paper/refs.bib`, and record any unresolved citation or
priority issue. Report what was searched and when. Do not invent bibliographic
fields or turn a literature inference into a claim of novelty.

Link the matrix and verified bibliography from `STATE.md` so writing and review tasks can reuse them.

When supporting a new paper's writing plan, identify relevant source sections
for content coverage and clear exposition. Explain why each paper is useful for
the current contribution type and readership; the closest technical work need
not be the strongest writing example. Use
`.paper-writing/skills/cpw-write/references/writing-from-related-work.md`
and link the resulting notes from `STATE.md` for later reuse.
