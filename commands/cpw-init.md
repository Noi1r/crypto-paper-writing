argument-hint: [paper-project-directory]

Use the current directory unless a project path is given. Copy missing files
from `.paper-writing/templates/blackboard/` and, if `paper/` is empty, copy
`.paper-writing/templates/paper/` into it. Never overwrite existing work.
Read `STATE.md` and ask only for missing paper-specific facts: topic, target
venue, deadline, intended contribution, and source locations. Record a concise
writing plan and the venue-rule verification task in `STATE.md`.
